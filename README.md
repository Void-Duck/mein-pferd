# Mein Pferd 🐴

Pferde-Tamagotchi für Alea: Pferd erstellen, füttern, pflegen und mit Minispielen Münzen verdienen.

**Spielen:** https://void-duck.github.io/mein-pferd/

**Auf dem iPhone installieren:** Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Danach immer über das Symbol starten.

Dieses Repo enthält nur die fertige Web-App. Die Quellen liegen im privaten Repo `Meine-Apps` im Ordner `Pferde/`
und werden mit `sh Pferde/web/deploy-pages.sh` hierher veröffentlicht.
